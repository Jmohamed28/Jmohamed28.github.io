Privacy Policy

Clipper · last updated 18 October 2026

Clipper is a personal command-line tool that runs on its operator's own computer. It turns long videos into short vertical clips and uploads them to that same person's TikTok account. There is no Clipper server, no hosted service and no account to sign up for. This policy describes what the tool does with data on the machine it is installed on.

Who this covers

Clipper is operated by a single person for their own TikTok account. The only TikTok account involved is the operator's own, connected by the operator through TikTok's own authorization screen. Clipper does not act for anyone else and has no other users.

What is stored, and where

Everything below is written to the folder Clipper is installed in, on the operator's computer. None of it is transmitted anywhere except to TikTok, as described in the next section.

DataWhyKept until
TikTok access token, refresh token and open_id To upload videos to the operator's own TikTok account without signing in again The operator deletes the file or revokes access in TikTok
TikTok app client key and client secret To refresh the access token when it expires The operator deletes the file
Video files the operator chose to clip, and the clips made from them These are what gets uploaded The operator deletes them
Clip captions, titles, scores, timestamps and upload results To queue clips, order them and record which ones were sent The operator deletes them

Token files are written with permissions that allow only the operator's own user account to read them.

What is sent to TikTok

When the operator queues a clip and it comes due, Clipper sends to TikTok's Content Posting API:

  • the video file itself;
  • the caption the operator wrote or approved, where the chosen route carries one;
  • the posting settings the operator selected, such as visibility and whether the video is a paid partnership;
  • the access token that identifies the operator's own TikTok account.

TikTok's handling of that content is governed by TikTok's own privacy policy.

What is not done

  • No data is sold, rented or shared with any third party.
  • There is no analytics, telemetry, crash reporting or usage tracking of any kind.
  • No advertising network, data broker or tracking service is used.
  • No data about any person other than the operator is collected. Clipper does not read followers, comments, messages, profiles or anyone else's content.
  • No cookies are set; this website is static and has no scripts.

Third parties Clipper talks to

Clipper contacts only the services the operator points it at:

  • TikTok, to authorize the account and upload videos.
  • The video host the operator supplies a link to, to download the source footage the operator has rights to use.
  • Anthropic, only if the operator supplies an API key, and only to send a transcript so clip-worthy moments can be chosen. This is optional and off unless a key is set.

Removing your data

To disconnect Clipper from TikTok, open TikTok, go to Settings and privacy → Security and permissions → Manage app permissions, and remove the app. To erase the stored credentials, delete tiktok_auth.json from the Clipper folder. To erase everything else, delete the Clipper folder.

Children

Clipper is not directed at children and is not intended for use by anyone under the minimum age of the platforms it connects to.
